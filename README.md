# 🎬 Netflix Data Analysis Project

## 📌 Project Overview

This project analyzes Netflix's content library using Python, Pandas, Matplotlib, and Seaborn.

The objective is to explore Netflix data and identify trends related to content type, countries, ratings, directors, and content growth over time.

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset

Dataset: Netflix Titles Dataset

The dataset contains information about Netflix Movies and TV Shows, including:

- Title
- Type (Movie / TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Date Added
- Duration

---

## 📊 Analysis Performed

### 1. Movies vs TV Shows Analysis
- Compared the number of Movies and TV Shows available on Netflix.

### 2. Top Content Producing Countries
- Identified countries contributing the most content to Netflix.

### 3. Content Growth Over Years
- Analyzed how Netflix expanded its content library over time.

### 4. Top Directors Analysis
- Identified directors with the highest number of titles on Netflix.

### 5. Top Ratings Analysis
- Examined the most common content ratings available on Netflix.

---

## 📈 Visualizations

The project includes the following visualizations:

- Movies vs TV Shows
- Top Countries
- Content Growth by Year
- Top Directors
- Top Ratings

---

## 🔍 Key Findings

- Netflix contains significantly more Movies than TV Shows.
- The United States contributes the highest amount of content.
- India is among the leading content-producing countries.
- Netflix experienced rapid content growth after 2016.
- Content additions peaked around 2019.
- TV-MA is the most common rating on Netflix.
- Netflix has expanded globally by increasing international content.
